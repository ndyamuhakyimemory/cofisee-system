Backup & Settings

Important: This is an offline, single-device application. Your records are stored in this browser on this device. Clearing browser data, changing browsers or losing the device can remove records. Export backups regularly and keep a copy somewhere safe.

Excel sharing and safe record merging

Export all records into one Excel-compatible workbook with separate worksheets. For a one-file transfer that opens with the current records already inside, use “Download COFISEE with all records”. Share that HTML file using Bluetooth, Quick Share or USB. On a new device, opening the portable file seeds its browser with the embedded records. On a device that already has COFISEE data, use “Import Excel workbook” and select the portable HTML file to ADD its records without replacing existing records.

Import mode: ADD records (Option A). Existing records are retained. Matching IDs are skipped; conflicting records are flagged and never silently overwritten.

Legacy backup and CSV

JSON backup restoration is retained for emergency recovery. It replaces current records, so use the Excel import above for ordinary device-to-device sharing.

58mm Bluetooth thermal printer

COFISEE receipts use your supplied OFFICIAL PAYMENT RECEIPT layout and are formatted for 58mm thermal paper. Pair the printer in Android Bluetooth settings, then enable its compatible printing service/app. When you print a receipt, choose that printer in the Android print screen. Some Bluetooth Classic printers require a companion printing app; Chrome does not support every raw Bluetooth printer directly.

Receipt paper: 58mm · Layout: COFISEE official payment receipt · Printing: Android system print dialog
